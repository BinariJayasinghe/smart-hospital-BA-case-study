# Smart Hospital Dataset

## Overview

This dataset was created for the Smart Hospital Management System Business Analysis Case Study and Power BI Dashboard.

The data simulates hospital operations including patient appointments, billing, waiting times, medicine inventory, and patient satisfaction metrics.

---

## Dataset Information

| Attribute | Description |
|------------|------------|
| Patient_ID | Unique patient identifier |
| Patient_Name | Patient name |
| Age | Patient age |
| Gender | Male/Female |
| Department | Hospital department |
| Doctor_Name | Assigned doctor |
| Appointment_Date | Appointment date |
| Appointment_Status | Completed, Pending, Cancelled |
| Waiting_Time_Minutes | Patient waiting time |
| Consultation_Fee | Consultation charge |
| Billing_Status | Paid or Unpaid |
| Payment_Method | Cash, Card, Online |
| Medicine_Name | Prescribed medicine |
| Medicine_Stock | Available stock quantity |
| Inventory_Status | Available or Low Stock |
| Patient_Satisfaction | Satisfaction rating (1–5) |

---

## Purpose

The dataset supports analysis of:

- Patient volume trends
- Appointment performance
- Revenue generation
- Waiting time analysis
- Billing performance
- Inventory management
- Patient satisfaction monitoring

---

## Dashboard KPIs

The following KPIs were derived from this dataset:

- Total Patients
- Total Revenue
- Average Waiting Time
- Patient Satisfaction Score
- Appointment Status Analysis
- Inventory Status Monitoring

---

## Disclaimer

This is a synthetic dataset created for educational and portfolio purposes only. It does not contain real patient information and should not be used for medical decision-making.
